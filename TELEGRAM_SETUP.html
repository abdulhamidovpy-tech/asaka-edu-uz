🤖 Telegram Bot O'rnatish

Saytdagi xabarlarni to'g'ridan-to'g'ri Telegram ga yuborish uchun

1-qadam: BotFather ni topish

1. Telegramni oching

2. Qidiruv satriga @BotFather deb yozing

3. Rasmiy BotFather ni topib, unga yozing:

/newbot

2-qadam: Bot yaratish

BotFather sizdan quyidagilarni so'raydi:

Bot nomi: Asaka MTB Bot (yoki istalgan nom)

Username: asaka_mtb_bot (yoki istalgan username)

Bot yaratilgandan keyin sizga token beriladi:

1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
⚠️ Muhim: Bu tokenni hech kimga bermang!

3-qadam: Chat ID ni olish

1. Telegramda @userinfobot ni toping

2. Unaga /start deb yozing

3. Bot sizning ID raqamingizni ko'rsatadi

Masalan:

id: 123456789

4-qadam: Config faylni tahrirlash

js/config.js faylini oching va quyidagilarni kiriting:

const TELEGRAM_CONFIG = { BOT_TOKEN: '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz', CHAT_ID: '123456789' };

5-qadam: Test qilish

1. Saytni oching

2. "Kontaktlar" bo'limiga boring

3. Formani to'ldiring va "Yuborish" tugmasini bosing

4. Telegramingizga xabar kelishi kerak!

✅ Agar xabar kelsa - muvaffaqiyatli ishlayapti!

Qo'shimcha sozlamalar

Bot ni faqat o'zingizga xabar yuborsin:

1. @BotFather ga yozing:

/mybots

2. Botni tanlang

3. "Bot Settings" ni bosing

4. "Group Privacy" ni "Turn off" qiling (agar guruhda ishlatsangiz)

Xatoliklar

"Message can't be sent" xatosi:

- Bot token noto'g'ri ekanligini tekshiring

- Chat ID noto'g'ri ekanligini tekshiring

- Bot ga birinchi marta /start yuborganingizga ishonch hosil qiling

Hammasi tayyor!

Endi saytdagi xabarlarni asosiy saytdan yuborishingiz mumkin.
